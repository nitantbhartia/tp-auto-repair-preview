# T P Auto Repair preview

A custom bilingual marketing site for T P Auto Repair, using the shared premium website structure with a distinct precision-garage art direction: asphalt black, oxidized orange, inspection-grid linework, automotive photography, and direct-call conversion paths.

The page includes responsive navigation, public rating proof, six published service lines, shop details, process guidance, FAQ, English/Spanish copy switching, and a dedicated rating-source route.

See [SOURCES.md](SOURCES.md) for the fact ledger and [DESIGN.md](DESIGN.md) for the durable design context. The images in `assets/` are illustrative concepts and should be replaced with approved company photography before final publication.
